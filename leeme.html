Cómo jugar

  1. Reparte un cartón a cada persona (o por parejas). Cada cartón tiene 25 canciones distintas.
  2. Abre el panel (ver abajo), pulsa ▶ Empezar y dale al play del reproductor.
  3. Cada vez que suene una canción, quien la tenga en su cartón la tacha.
  4. Se canta línea (5 en raya) y después bingo (cartón completo).

Ideas para que dure más y haya premios:

  • Ronda 1: línea horizontal.
  • Ronda 2: doble línea.
  • Ronda 3: cartón lleno (bingo).
  • Comodín: si suena una canción que no tiene nadie, se canta un "minipremio" (un chupito, un baile…).

Panel del presentador (presentador.html)

Lo más fácil: ábrelo directamente en el navegador del móvil o del ordenador, sin instalar nada:

👉 https://thesorian.github.io/bingo-cumple40/

También está en la carpeta, pero entonces hace falta un servidor local para el vídeo de

YouTube (con doble clic en el archivo los previews de Spotify sí suenan, pero YouTube no).

En PowerShell:

cd "E:\Gabi\Bingo Musical"
python -m http.server 8777

Y abre en el navegador: http://localhost:8777/presentador.html

⚠️ Usa localhost, no 127.0.0.1: YouTube no deja reproducir sus vídeos cuando la página se sirve desde una dirección IP. Si lo abres en el móvil por la red wifi, usa el nombre del equipo (por ejemplo http://mi-pc:8777/presentador.html), no la IP.

Qué hace:

  • ▶ Siguiente canción avanza el orden (también espacio o →; ← va atrás).
  • Reproductor con dos pestañas:
    • Spotify · 30 s — preview oficial de Spotify, sin login ni anuncios. Play/pausa, barra para avanzar y botón ↻ para repetir. Es lo más cómodo para el bingo.
    • ▶ YouTube — el vídeo de la canción, por si quieres oírla entera. Ninguno de los dos botones abre pestañas nuevas: cambian el reproductor aquí mismo.
  • Muestra canción actual, siguiente, progreso y las últimas canciones cantadas.
  • Nueva partida mezcla las canciones y vuelve a empezar (para una segunda ronda).
  • ↺ Reiniciar vuelve a empezar con el mismo orden (por si te equivocaste).
  • Comprobar cartón: elige el número de cartón y marca en verde las canciones que ya han sonado, con aviso de ¡LÍNEA! o ¡BINGO!.
  • El progreso se guarda en el navegador: si cierras, sigue donde lo dejaste.
  • En la web publicada puedes compartir el enlace con quien quieras; los PDF también están ahí (cartones.pdf y hoja-de-control.pdf). Es pública, pero no está enlazada desde ningún sitio.

Regenerar o cambiar cosas

python generar_bingo.py                       # 30 cartones, título "Cumple 40"
python generar_bingo.py --cartones 50         # más cartones
python generar_bingo.py --semilla 7           # otra combinación de canciones y otro orden
python generar_bingo.py --titulo "Cumple 40"  # cambia el título de los cartones
python generar_bingo.py --actualizar-previews # renueva los audios de 30 s de Spotify
python buscar_youtube.py                      # busca vídeos para las canciones que no tengan
  • Para cambiar canciones, edita datos/canciones.json y vuelve a ejecutar el script. Cada canción necesita titulo, artista, ms y uri; los campos preview y youtube_id los rellenan los dos scripts de arriba.
  • Si un preview de Spotify deja de sonar con el tiempo, ejecuta --actualizar-previews.
  • Requiere Python 3 y pip install reportlab. Los vídeos se buscan con buscar_youtube.py (no necesita claves: lee los resultados de YouTube).
  • Los cartones que genera el script no se repiten y cada canción sale entre 7 y 8 veces (reparto equilibrado).
